Phase 1 Test Files

This package contains Phase 1 Front End requirements-test inputs and
expected behaviours for TC01–TC46.

Folders

-   inputs/: complete transaction input streams plus starting user,
    game, and collection fixtures.
-   expected/: expected Front End behaviour and Daily Transaction File
    requirements.

Important

The supplied project requirements specify required behaviour and Daily
Transaction File formats, but they do not prescribe exact terminal
prompt/error-message wording. For that reason, the .expout.txt files
describe the required observable behaviour rather than inventing exact
console sentences.

The project document also contains an apparent inconsistency in the
Available Games File description: it calls the lines 49 characters in
one place and 42 characters in the constraints. The fixture files here
are therefore readable Phase 1 test data rather than pretending that an
unresolved fixed-width interpretation has been confirmed. Ask the
TA/client which width is intended before locking exact fixed-width game
fixtures.

These files should be reviewed by the group and adjusted if the
TA/client has issued requirement changes outside the uploaded project
handout.

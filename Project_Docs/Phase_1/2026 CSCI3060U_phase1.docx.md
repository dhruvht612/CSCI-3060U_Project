**Course Project Phase \#1 \- Front End Requirements**

# Due Friday, October 2nd, 2026 (8:00pm)

In this assignment, you will analyze the requirements for the Front End and in true XP fashion represent those requirements as a set of requirements tests.

Create and organize a complete set of requirements tests for the Front End of the Digital Games Distribution System, to test for every required behaviour.  Do not write any programs yet.  Each test should be a complete test session input stream in a separate file.  Test files should be organized into directories.

* You should hand in:

  1) A list of all your test cases and what they are intended to test (a table of test names and intentions, in English)

  2) For each test case, the actual test input files and expected output files (as text file printouts)

  3) A test plan document, outlining how your tests are organized (in directories or whatever), how they will be run  (such as shell scripts or DOS batch files), and how the output will be stored and organized for reporting and comparison with later runs (make text file printouts of any directory structures and script files created)

* Hand-ins must be completed electronically through Canvas by 8:00pm on the due date. Your electronic submission should include your list of test cases (doc, pdf), the input and output files for each test case (zip containing txt files), and your test plan document (doc, pdf). You must also have committed all files to your Github repository by the due date.

* If Generative AI was used in your project, you must also submit the complete history of prompts and responses pertaining to the work you submitted; otherwise, you must submit a distinct file containing a written statement promising that no Generative AI was used in this project phase. Submissions with neither of these will receive a grade of zero.
